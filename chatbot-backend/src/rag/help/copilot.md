# Ask Satya (the copilot)

Ask questions in plain language: "Where is PO-1001?", "Why is INV-041 on
hold?", "Which MSME payments are due this week?" Answers are built only
from your records — every number links to evidence. When AI keys are
exhausted the copilot answers in evidence-only mode and says so. Chat is
read-only; it never approves, pays or sends anything.
